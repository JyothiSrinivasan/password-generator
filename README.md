# Random Password Generator

A simple Python program that generates an 8-character string using uppercase letters, lowercase letters, and digits.

## How to Run

Run the Python script or Jupyter Notebook cell. A randomly generated string will appear in the output.

## Concepts Used

- `random` and `string` modules
- `random.choice()`
- Generator expressions and `join()`

## Note

This is a practice project. Python’s `random` module is not suitable for secure passwords; use `secrets` for real password generation.
